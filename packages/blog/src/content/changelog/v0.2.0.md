## What's new in v0.2.0

### Playback fixes
- New tracks and video walls load again — YouTube changed how it serves media and the proxy was still asking the old way
- Streams no longer stop partway through and stall; media is fetched in small pieces that retry on their own
- The video wall pulls roughly a tenth of the data it used to, for the same picture
- Cached tracks survive server restarts instead of being cleared on every deploy

### NPC DJs
- An NPC DJ can hold the decks when nobody else is playing — walks to the booth, wanders the dancefloor between sets
- Hands over gracefully when a real DJ steps up, and takes the booth back when the queue empties
- Toggle per room when creating it: off, fill-in, or resident
- New default "Mutant Rotation" playlist

### Playlists
- Import a whole YouTube playlist by pasting its URL, from My Playlists or MutantTube
- Audio reactivity is computed up front on the server, so visuals stay locked to the beat without every machine crunching audio
- Scrubbing and skipping within a track is much quicker

### Reliability
- Fixed DJ queue rotation, late-join seeking, and stuck turns when a DJ ran out of tracks
- Login and room joins no longer fail intermittently
- The game server can't be knocked offline by malformed requests from the open internet
